# Objavljene odluke Fondacije

Tekstovi koje sajt prikazuje na `/odluke` (Statut čl. 21 i 22 st. 4). Svaki fajl je
**doslovna kopija** odluke iz `arhiva-fondacije/`. Menja se samo arhiva, pa se fajl ovde
prepisuje; test `odluke-fondacije-izvor.test.ts` pada ako se razidu.

Spisak, datumi i naslovi su u `src/lib/odluke-fondacije.ts`. Folder je deo sajta i ide u
javni repo (`scripts/osvezi-javni-repo.sh`). U njega ne ide ništa sa ličnim podacima
osim imena predsednika UO, koje je javno u APR-u.
