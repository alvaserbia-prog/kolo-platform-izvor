BPG, заявление о достоверности и номер телефона носителя доступны только административной команде. Карта использует общедоступные картографические подложки, которым местоположение не передаётся как данные, связанные с пользователем; поиск адреса при подаче заявки выполняется из браузера заявителя к сервису OpenStreetMap Foundation (Nominatim, Соединённое Королевство). |

| **Срок хранения** | Номер телефона носителя удаляется решением о заявке; остальные данные: пока хозяйство одобрено и имеет хотя бы одного члена. При прекращении хозяйства, по любому основанию, наименование, описание, адрес, местоположение и BPG удаляются, а точка снимается с карты. При выходе и закрытии учётной записи член перестаёт отображаться. Связь члена с хозяйством, порядок присоединения, заявление о достоверности и сведения о прекращении сохраняются под псевдонимом, для правила об одном хозяйстве, списания при прекращении и порядка действий при ложном заявлении; при прекращении статуса они разделяют судьбу учёта вкладов (операция № 4). |
| **Меры защиты** | Только совершеннолетние учётные записи; заявку и каждое присоединение Фонд проверяет до отображения; выписка из Реестра сельскохозяйственных хозяйств не собирается, и BPG в реестре не проверяется; Фонд разговаривает только с носителем и номера телефонов остальных членов не собирает. |
| **Примечание** | Хозяйство не имеет записи в Протоколе; записи вклада хозяйства ведутся в операции № 4, а имя и фамилия членов в операции № 21. Разговор с носителем служит одобрению хозяйства, а не подтверждению реальности. Заявка о хозяйстве приносит носителю, который является пользователем, предложение о списке для звонка (операция № 24); номер для списка носитель оставляет отдельно, когда соглашается на звонок. |

Несовершеннолетние пользователи не охватываются. |
| **Категории данных** | Имя и фамилия, псевдоним учётной записи, случай первого внесения (хозяйство, публичное пожертвование, кооператив, покровительство, список для звонка), момент внесения и изменения. Источник: сам пользователь (хозяйство, покровительство, список для звонка), запись о публичном пожертвовании и кооператив. |
| **Правовое основание** | Внесение: исполнение договора (пункт 2 части 1 статьи 12 ЗЗПЛ): имя вносится ради участия, которое пользователь сам запросил. Сохранение после прекращения этого участия и сравнение с другими учётными записями: законный интерес Фонда (пункт 6 части 1 статьи 12 ЗЗПЛ) в том, чтобы одно и то же лицо не вело несколько учётных записей и чтобы основание учтённого вклада можно было проверить. |

Имя не отображается другим пользователям и не вносится в учёт вкладов; оно доступно административной команде, самому пользователю, администратору кооператива в отношении членов его кооператива (операция № 19) и члену Коло, который звонит пользователю из списка для звонка: по клику и только пока звонок открыт (операция № 24). |
| **Передача в третью страну** | Только по общим положениям. |
| **Срок хранения** | Пока существует учётная запись; удаляется при прекращении статуса. Прекращение статуса члена кооператива, выход из хозяйства и отзыв согласия на публикацию имени при публичном пожертвовании внесение не удаляют. |
| **Меры защиты** | Отдельный учёт; одно имя на учётную запись: иное имя не перезаписывает внесённое; исправление только по возражению; имя не вносится в описание записи ПОЕН, в уведомления и в журнал аудита; имеющиеся имена ретроактивно не переносятся. |
| **Примечание** | Внесение не является верификацией и никогда не подтверждает реальность. Проверка соразмерности: имя не используется ни для какой другой цели, никакие данные из документов не обрабатываются, и оно удаляется при прекращении статуса, поэтому интерес Фонда преобладает; лицо может подать возражение. |

Ваучер берётся без очереди: автоматизированного принятия решений в смысле статьи 38 ЗЗПЛ нет; по возражению решает человек. |

## Заключительные положения

Реестр обновляется при каждом изменении операции обработки или технических и организационных мер защиты, а новая операция вносится вместе с изменением Оценки воздействия на защиту персональных данных. Реестр предоставляется Уполномоченному по информации общественного значения и защите персональных данных по запросу.

Настоящий Реестр вступает в силу со дня его принятия.
